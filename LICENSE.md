# Licenses

This repository bundles three implementations of KAMD. Each one is licensed to match the engine it modifies or builds on.

| path | license | why |
|---|---|---|
| `openmm/` | MIT (see `openmm/LICENSE`) | standalone Python package that uses the OpenMM API |
| `gromacs/` | GNU LGPL v2.1 or later (see `gromacs/COPYING`) | the patch creates a derivative work of GROMACS |
| `amber/` | terms of the Amber pmemd source license | the patch modifies pmemd, which is distributed under the Amber license |
