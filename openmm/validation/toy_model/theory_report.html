KAMD 重置的能量重分配：为什么"速率守恒"不等于"温度守恒"

配合 openmm/validation/toy_model/RESULTS.md 阅读。所有数值来自同一组玩具模型模拟（LJ 液体，120 K，两个 13 原子二十面体团簇）。

结论。KAMD 的 pseudo-BD 重置由两部分组成：Maxwell-Boltzmann（MB）重采样和保速率的定向推动（redirect）。前者保持正则分布，后者不保持。

Redirect 保住每个原子的速率，因此总动能不变。但它把基团内部的动能搬进基团的质心平动：对一个 13 原子团簇，质心动能从 1.5 kT 升到约 14 kT，内部振动动能从 18 kT 降到约 5 kT。这个数可以解析算出，和实测吻合。

体系在弛豫回来之前采到的构型，对应的是"集体坐标偏热、内部坐标偏冷"的非平衡状态。偏差大小由弛豫时间与重置间隔之比决定，同一个机制同时带来加速和偏差。

§1重置的形式化

记相空间点为 (x, p)，正则分布为 π(x, p) ∝ exp[−βH(x, p)]，其中 H = U(x) + Σi pi²/2mi，β = 1/kT。一次 KAMD 重置是一个只改动量、不改位置的随机映射：

1. p̃ᵢ ~ N(0, mᵢkT) 对所有原子（MB 重采样） 2. d_g ~ 单位球面均匀分布 每个基团 g 一个方向 3. S_g(x) = 基团 g 的第一溶剂层 ∪ 表面原子 （依赖构型 x） 4. pᵢ' = mᵢ |ṽᵢ| d_g 若 i ∈ S_g(x) pᵢ' = p̃ᵢ 否则 (1)

一个只改动量的随机核 K(p → p′ | x) 保持 π 不变的充要条件是：对每个 x，K 把 MB 分布映射回 MB 分布。

∫ φ_MB(p) K(p → p' | x) dp = φ_MB(p') 对所有 x (2)
  • 只做 MB 重采样（第 1 步）：输出的 p′ 就是新抽的 MB 样本，与输入无关，(2) 平凡成立。实测中这一对照组的所有构型观测量都与参考一致（P(r) χ² p = 0.99，Rg 方差比 1.001 ± 0.006）。
  • 加上 redirect（第 2–4 步）：Sg 中所有原子的速度方向完全一致。这样的 p′ 分布集中在一个低维子集上（同组原子速度平行），不是各向同性的 Gaussian，(2) 不成立。而且 Sg 依赖 x，所以偏离 MB 的方式还和构型有关。

严格来说，触发时刻依赖动量的历史（零点穿越），所以即使只做 MB 重采样，也需要额外论证才能保证不变性。本报告只依据数据说明：这一部分在当前精度下没有可测偏差。

§2速率守恒，但能量换了地方

一个基团（n 个原子，总质量 M）的动能可以严格拆成两项：

KE_g = KE_com + KE_int KE_com = |Σᵢ pᵢ|² / 2M （3 个自由度） KE_int = KE_g − KE_com （其余 3n − 3 个自由度） (3)

温度是按自由度定义的：平衡时每个二次型自由度平均 ½kT。所以正则平衡下 ⟨KEcom⟩ = 3/2 kT，⟨KEint⟩ = 3(n−1)/2 kT。Redirect 不改 KEg，但会改变它在两项之间的分配。

解析期望值

设原子质量相同（玩具模型正好如此），ns 个原子被对齐到方向 d，其余原子保持 MB 速度。用 MB 速率的两个矩 ⟨|v|²⟩ = 3kT/m 和 ⟨|v|⟩² = 8kT/(πm)：

⟨|Σ_aligned |vᵢ||²⟩ = n_s · 3kT/m + n_s(n_s − 1) · 8kT/(πm) ⟨|Σ_rest vⱼ|²⟩ = (n − n_s) · 3kT/m 交叉项平均为零（d 与其余速度独立） ⟨KE_com⟩ = 3/2 kT + 4 n_s (n_s − 1) kT / (π n) (4) ⟨KE_int⟩ = 3(n − 1)/2 kT − 4 n_s (n_s − 1) kT / (π n) (5)

第二项来自"同方向速度不再互相抵消"：ns 个同向向量的模长平方按 ns² 增长，而随机方向只按 ns 增长。

§3弛豫与偏差的标度

重置之后，多余的集体动能通过碰撞和 Langevin 摩擦重新均分。实测的团簇质心动能在 0.1 ps、0.5 ps、1.7 ps 时分别为 14.0、4.4、1.5 kT，近似指数衰减，τ ≈ 0.35 ps（γ = 1 ps⁻¹）。设每次重置注入超额能量 ΔE，重置间隔为 Δ，则时间平均的超额能量为：

⟨KE_com⟩_t ≈ 3/2 kT + ΔE · (τ/Δ) · (1 − e^(−Δ/τ)) (6)
条件Δ（ps）式 (6)，τ = 0.35 ps实测时间平均

这个简单模型已经能解释观测到的偏差顺序：τ/Δ 越大，体系花在非平衡状态的时间比例越高，偏差越大。

  • 频繁重置（Δ 小）比默认参数偏差大：能垒 0.26 kT 对 1.35 kT，参考值 2.00 kT。
  • 低摩擦（τ 大）偏差更大：γ = 0.1 时 Rg 方差比降到 0.27。
  • 高摩擦（τ 小）偏差较小但仍存在：γ = 10 时 Rg 方差比 0.89。

注意：动能的偏差会在构型上留下痕迹。偏热的集体坐标在弛豫期间爬得更高、越过能垒，于是 P(r) 被压平；偏冷的内部模式振幅偏小，于是 Rg 分布变窄。这些构型都被计入统计。仅在"远离重置"的时刻取样并不能消除偏差，因为构型本身是由之前的非平衡轨迹带过来的。

§4为什么这不是"升温"

升温方法（REST、simulated tempering 等）的每个副本或温度都对应一个已知的玻尔兹曼分布，这正是能交换或重加权回目标温度的前提。KAMD 不满足这个前提：

  1. 它同时制造了偏热的自由度（基团间相对运动）和偏冷的自由度（基团内部），没有任何单一温度能同时描述两者。
  2. 它的稳态分布没有解析形式，所以不能用重加权精确修正。

更贴切的类比是 TAMD / d-AFED 这类"只加热选定慢变量"的方法。区别在于：TAMD 有绝热分离理论，知道被加热坐标的分布，可以修正；KAMD 不需要预先选 CV，但也没有这层理论保证。

§5对蛋白质的推论推测，未测

对大基团（n 很大、表面原子比例 f = ns/n），式 (4) 给出：

⟨KE_com⟩ ≈ (4/π) f² n kT 被搬进质心的比例 ≈ (8 / 3π) f² ≈ 0.85 f² (7)
  • 内部"冷却"的相对幅度随 f² 变小：f = 0.3 时约 8%，远小于玩具模型的 66%。所以蛋白质内部构象的偏差可能较弱。
  • 但注入集体运动的绝对能量随 n 线性增长。对 1000 个原子、f = 0.3 的结构域，粗估质心动能约 100 kT，而正则值是 1.5 kT。结构域之间相对运动的"过热"可能比玩具模型更强。
  • 真实体系的质量不等，有约束（SHAKE），还有水的流体动力学，式 (7) 只能给数量级。偏差到底多大，必须在真实蛋白上用同样的对照（普通 MD / KAMD / MB-only）实测。

§6与其他方法结合时的含义

组合能否消除偏差原因
WE 轨迹直接用 KAMD 动力学否WE 对给定动力学是无偏的，给出的是 KAMD 动力学的分布和速率，不是物理体系的。
REST，只在高副本用 KAMD部分，不严格交换准则假设每个副本采样各自的玻尔兹曼分布；基态副本用普通 MD 可以稀释偏差，残余多少需要测。
KAMD 找态 → 普通 MD 短轨迹 → MSM是统计权重完全由无偏动力学给出；KAMD 只决定从哪里开始。
KAMD 作为 MC 提议，加接受/拒绝理论上可以，实际很难重置映射把速度压到一个低维子集上，不保体积也不可逆，提议概率之比没有定义。

§7可能的修正方向未验证

  • 降低重置频率。由式 (6)，偏差约正比于 τ/Δ。可以在玩具模型上扫 pseudobd_cycles，找"偏差 < 0.1 kT 且仍有加速"的区间。
  • 用非对角质量矩阵代替推动。对任意正定质量矩阵 M，哈密顿动力学（配合对应的恒温器）都保持构型分布 exp(−βU)。把基团的"集体质量"调小，集体运动就会变快，而构型分布严格不变，思路类似氢质量重分配（HMR）。这可能是"加速集体运动且保持正则"的一条严格路线，需要专门推导和测试。
  • 把 KAMD 定位为探索器。搜索阶段用 KAMD，定量阶段（布居、PMF、速率）交给无偏方法。

§8本报告的局限

  • 式 (4)–(5) 假设原子质量相同、对齐原子的速率独立服从 MB，忽略了键约束；这在玩具模型中成立，在蛋白质中只是近似。
  • 式 (6) 是唯象的单指数模型，τ 是从三个时间点粗略拟合的，只用来说明标度。
  • "Redirect 不保持正则分布"由式 (2) 得出，是严格的；"偏差在构型上有多大"只能由模拟给出，这里的数值只适用于这个玩具模型。
  • MB-only 触发规则的严格不变性没有证明，只是在当前精度下没有观察到偏差。
